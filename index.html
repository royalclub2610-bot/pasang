Memuat...

Cara memasang

  1. Buka file Pasang-...bat dari folder Unduhan.
  2. Tekan tombol apa saja untuk melanjutkan. Pintasan baru muncul di Desktop.
  3. Klik ikon tersebut untuk membuka aplikasi di browser.
Windows atau browser mungkin menampilkan peringatan karena file ini belum bertanda tangan digital. Lanjutkan hanya jika Anda menerimanya dari email undangan resmi. Anda tidak perlu menonaktifkan antivirus atau Windows Defender.

Yang dilakukan installer

  • Menyimpan satu file ikon di folder %LOCALAPPDATA%\LinkToIcon.
  • Membuat satu pintasan di Desktop.
  • Tidak butuh hak Administrator, tidak mengubah registry, tidak mengirim data. Isinya bisa dibaca dengan Notepad.

Jika tombol tidak muncul

  1. Buka halaman ini di Chrome.
  2. Ketuk menu ⋮ di kanan atas.
  3. Pilih Instal aplikasi atau Tambahkan ke layar utama.

Samsung Internet: menu → Tambahkan halaman ke → Layar utama.

Pemasangan paling andal lewat Safari. Salin tautan ini lalu buka di Safari.

Cara memasang

  1. Buka halaman ini di Safari.
  2. Ketuk tombol Bagikan (kotak dengan panah ke atas).
  3. Pilih Tambah ke Layar Utama, lalu ketuk Tambah.

Cara memasang

  1. Chrome atau Edge: klik ikon pasang di ujung kanan kolom alamat, atau menu → Instal.
  2. Safari 17 atau lebih baru: menu File → Tambahkan ke Dock.

Browser lain mungkin tidak mendukung pemasangan. Gunakan alternatif di bawah.

Setelah terpasang, cukup tekan ikon untuk membuka aplikasi.

Pertanyaan umum

Apakah aman? Apa yang dilakukan installer Windows?

Installer hanya menyimpan satu file ikon di folder LinkToIcon (di profil Anda) dan membuat satu pintasan di Desktop. Tidak butuh hak Administrator, tidak mengubah registry atau pengaturan Windows. Seluruh isinya bisa dibaca dengan Notepad.

Windows atau browser menampilkan peringatan. Normalkah?

Ya, karena file belum bertanda tangan digital. Lanjutkan hanya jika Anda menerimanya dari email undangan resmi. Anda tidak perlu mematikan antivirus atau Windows Defender.

Tombol Pasang aplikasi tidak muncul di Android.

Gunakan Chrome, lalu ketuk menu titik tiga dan pilih Instal aplikasi atau Tambahkan ke layar utama.

Bagaimana menghapus ikon?

Windows: hapus pintasan di Desktop (opsional: hapus folder %LOCALAPPDATA%\LinkToIcon). Android: tekan lama ikon lalu Copot atau Hapus. iPhone: tekan lama ikon lalu Hapus dari Layar Utama.

Ikon menampilkan "tidak tersedia" atau "akses dicabut".

Aplikasi sedang dinonaktifkan atau akses Anda dicabut oleh admin. Hubungi admin aplikasi.

Data apa yang dicatat?

Halaman ini mencatat jenis perangkat, browser, dan waktu untuk peristiwa membuka halaman, mengunduh installer, dan memasang aplikasi, dikaitkan dengan undangan Anda. Tidak ada data pribadi lain yang diambil.
